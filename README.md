## 🛠 Tech Philosophy · 技术与理念

- **边缘优先 (Edge First)**：全面采用 Cloudflare Pages 与 Cloudflare Workers 分布于全球 300+ 边缘数据中心，保证全球范围内近零延迟。
- **极简主义 (Vanilla & Lightweight)**：剔除臃肿依赖，注重核心功能与极速加载，全站支持响应式与暗色模式。
- **隐私保护与免绑卡**：不收集非必要隐私数据，不要求预绑信用卡，让工具回归工具本身。
