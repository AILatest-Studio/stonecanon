## 🛠 Tech Philosophy · 技术与理念

- **边缘优先 (Edge First)**：全面运行于 Cloudflare Workers 与 Cloudflare Pages 全球 300+ 边缘机房，极速首字响应。
- **极简主义 (Vanilla & Lightweight)**：拒绝过重前端框架包裹，纯粹、可靠、对移动端与桌面端自适应。
- **免绑卡与保护隐私**：免强迫注册，杜绝隐私滥用，优先提供无需信用卡的免费或轻量试用方案。
